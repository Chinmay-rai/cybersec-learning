# Day 1 - OSINT Challenge 

## Overview
Worked through a basic OSINT challenge focused on using publicly available data to extract useful information.

## Tools Used
- wigle.net  
- exif.tools  

## What I Did
- Started by analyzing available data and identifying possible leads  
- Used EXIF tools to extract metadata from images  
- Tried using Wigle to map network-related information (BSSID search)  

## Challenges Faced
- Wigle search results were not accurate and kept showing a default location (San Francisco) when searching via BSSID  
- This made it difficult to rely on it directly for location tracing  

## Observations
- The issue might be related to account limitations (email not verified / restricted search access)  
- Found that advanced search could potentially fix this, but haven’t tested it yet  

## Workaround
- Instead of relying completely on Wigle, used alternative and simpler methods to continue the challenge  
- Focused on validating information step by step rather than depending on a single tool  

## What I Learned
- OSINT is more about **thinking and patience** than just tools  
- Tools can fail or behave unexpectedly, so having alternative approaches is important  
- Verifying each step is better than blindly trusting outputs  

## Next Steps
- Verify Wigle account and test advanced search properly  
- Practice more OSINT challenges  
- Start exploring tools like Nmap for deeper technical understanding
