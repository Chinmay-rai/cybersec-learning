## What I Understood
- Linux commands follow a structured syntax with commands, options, and arguments  
- The terminal allows direct interaction with the operating system  
- Absolute paths specify the full location of a file or directory, while relative paths depend on the current location  
- Shortcuts like `..`, `.`, and `~` simplify navigation inside the file system
