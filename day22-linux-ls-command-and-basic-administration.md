# Day 22 – Linux ls Command and Basic Administration

## What I Did
- Studied the `ls` command in more detail  
- Learned how `ls -l` displays detailed information about files and directories  
- Understood the structure of the detailed output fields  
- Studied different Linux file types shown in the first field:
  - Directory
  - Regular file
  - Symbolic link
  - Socket
  - Pipe
  - Block file
  - Character file  
- Learned about file permissions, hard links, user owner, group owner, file size, and timestamps shown in the output  
- Studied how sorting works with the `ls` command  
- Learned options like:
  - `-t`
  - `-S`
  - `-r`
- Studied basic administrative commands such as:
  - `su`
  - `sudo`

## What I Understood
- The `ls -l` command provides detailed metadata about files and directories  
- The first character in the output identifies the file type  
- Linux permissions determine access control for files and directories  
- Different `ls` options can change how output is sorted and displayed  
- `su` and `sudo` are used for administrative access and privilege management  

## Concepts Covered
- `ls` command  
- `ls -l` output  
- Linux file types  
- File permissions  
- Hard links  
- Sorting options in `ls`  
- `su` command  
- `sudo` command  

## Key Takeaways
- Linux commands provide detailed information through different options and flags  
- Understanding file permissions and ownership is important for system administration and security  
- Administrative commands allow controlled access to higher privileges  
- Small command options can significantly change command behavior and output
