# Day 23 – Linux Permissions and Ownership

## What I Did
- Studied Linux file permissions  
- Learned how permissions are divided into three sets:
  - Owner
  - Group
  - Others  
- Studied permission types:
  - Read
  - Write
  - Execute  
- Learned what actions these permissions allow on files and directories  
- Understood important permission rules and combinations  
- Learned how to change file permissions using the `chmod` command  
- Studied two methods of using `chmod`:
  - Symbolic method
  - Octal method  
- Learned how to change file ownership using the `chown` command  

## What I Understood
- Linux permissions control access to files and directories  
- Different permissions provide different levels of access and functionality  
- Permissions behave differently for files and directories  
- `chmod` is used to modify permissions, while `chown` changes ownership  
- Octal permissions provide a compact way to represent permission combinations  

## Concepts Covered
- Linux permissions  
- Owner, group, and others  
- Read, write, execute permissions  
- Permission combinations  
- `chmod` command  
- Symbolic permissions  
- Octal permissions  
- `chown` command  

## Key Takeaways
- Permissions are one of the core security features in Linux  
- Understanding permissions is important for both Linux administration and cybersecurity  
- Symbolic and octal methods provide different ways to manage permissions  
- Ownership and permissions together control access within the system
