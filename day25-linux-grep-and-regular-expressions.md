# Day 25 – Linux grep and Regular Expressions

## What I Did
- Studied filtering input using the `grep` command  
- Learned basic usage of `grep` for searching patterns in files and input  
- Studied regular expressions and their two forms:
  - Basic Regular Expressions
  - Extended Regular Expressions  

- In Basic Regular Expressions, studied:
  - `.`
  - `[]`
  - `[^]`
  - `*`
  - `^`
  - `$`

- In Extended Regular Expressions, studied:
  - `+`
  - `?`
  - `{}`
  - `|`
  - `()`

- Learned how `grep` takes input from standard input (keyboard) when no file name is provided  
- Studied the `shutdown` command and its usage  

## What I Understood
- `grep` is used to search and filter text using patterns  
- Regular expressions make pattern matching more flexible and powerful  
- Basic and extended regular expressions provide different levels of pattern matching functionality  
- Standard input allows commands to process input directly from the terminal  
- Linux commands can process input and output streams efficiently through the command line  

## Concepts Covered
- `grep` command  
- Pattern matching  
- Basic regular expressions  
- Extended regular expressions  
- Standard input  
- Text filtering  
- `shutdown` command  

## Key Takeaways
- `grep` is one of the most important Linux text processing commands  
- Regular expressions allow efficient searching and filtering of data  
- Understanding pattern matching is useful for Linux administration and cybersecurity tasks  
- Linux commands become much more powerful when combined with regular expressions
