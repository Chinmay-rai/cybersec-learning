# Day 51 – SOC Alert Triage and Incident Reporting

## What I Did

- Completed hands-on SOC alert triage and incident reporting exercises
- Investigated multiple security alerts using a Tier 1 SOC analyst workflow
- Validated available evidence before deciding whether alerts should be closed or escalated
- Documented investigation findings in a structured format for higher-tier analysts
- Continued developing practical incident analysis and reporting skills

## Investigation Scenarios

Worked through investigations involving:

- Phishing email analysis
- Endpoint alerts
- Suspicious process execution
- Parent-child process relationships
- Authentication activity
- Security alert validation

## Practical Activities

- Investigated phishing email alerts using sender information, email authentication results, attachments, and message content
- Analyzed endpoint alerts involving suspicious process execution
- Reviewed authentication and system activity to understand the context of security alerts
- Distinguished legitimate administrative activity from potentially malicious behavior
- Wrote concise, evidence-based investigation notes for L1 → L2 escalation
- Prioritized alerts and determined appropriate response actions

## What I Understood

- Effective investigations require correlating multiple indicators rather than relying on a single IOC
- Parent-child process relationships provide valuable context during endpoint investigations
- Incident reports should focus on factual observations supported by evidence rather than assumptions
- The role of a Tier 1 SOC analyst extends beyond detection to include clear documentation and communication
- Well-structured investigation notes help higher-tier analysts continue investigations more efficiently
