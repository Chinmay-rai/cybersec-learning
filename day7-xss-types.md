# Day 7 – XSS Types

## What I Did
- Continued learning Cross-Site Scripting (XSS)  
- Focused on understanding different types of XSS  

## What I Understood
- Reflected XSS: input is immediately returned in response and executed  
- Stored XSS: input is saved and executed later  
- XSS depends on how user input is handled by the application  

## Observation
- Realized that same payload behaves differently depending on where input is used  
- Understanding context is important for exploitation  

## Learning
- XSS is not just about payloads, but about how input is processed  
- Need to analyze where input is reflected
