## What I Understood

- A detection is only useful when it produces meaningful and actionable alerts
- Too many false positives can create alert fatigue and make important threats harder to identify
- Detection rules need to be tested and tuned rather than deployed and forgotten
- Detection coverage and false-positive reduction need to be balanced
- Severity should reflect the importance and context of the detected activity
