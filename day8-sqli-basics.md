# Day 8 – SQL Injection Basics

## What I Did
- Learned about SQL Injection (SQLi)  
- Explored how user input can affect database queries  

## What I Understood
- SQLi allows injecting SQL queries into input fields  
- It targets the backend database instead of the browser  
- Happens when user input is not properly validated  

## Types
- Authentication bypass (e.g., `' OR 1=1 --`)  
- Basic idea of union-based SQLi  
- Basic idea of error-based SQLi  

## Learning
- Understood how SQLi can be used to bypass login systems  
- Learned difference between XSS (client-side) and SQLi (server-side)
